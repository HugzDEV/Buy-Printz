# Expected Database Tables for BuyPrintz Application

Based on the codebase analysis, here are all the tables that the application expects to exist:

## Core Tables
1. **orders** - Order management and tracking
2. **creators** - Creator marketplace users
3. **creator_templates** - Templates uploaded by creators
4. **banner_templates** - User-created banner templates
5. **canvas_states** - Canvas editor state management
6. **design_history** - Version history for designs
7. **user_profiles** - User profile information
8. **user_addresses** - User shipping addresses
9. **user_preferences** - User preferences and settings

## Business Card Tins
10. **business_card_tins** - Business card tin orders

## Creator Marketplace
11. **creator_followers** - Creator follower relationships
12. **creator_notifications** - Creator notifications
13. **creator_analytics** - Creator performance analytics

## Additional Tables (referenced in code)
14. **tin_skinz_orders** - Tin Skinz specific orders
15. **tin_skinz_templates** - Tin Skinz templates
16. **shipping_costs** - Shipping cost calculations

## Tables that might have been renamed:
- Check if any of these were accidentally renamed
- Look for tables with similar names but different casing
- Check for tables with extra underscores or different naming conventions
